# Contributor Covenant Code of Conduct (v2.1)

Our community is committed to providing a friendly, safe and welcoming environment for all.

All contributors are expected to adhere to the following code of conduct. Examples of expected behavior include:

- Be respectful and considerate in communications.
- Use inclusive language.
- Gracefully accept constructive criticism.

Unacceptable behavior includes harassment, discrimination, or abusive language.

If you witness or are subjected to unacceptable behavior, please report it in accordance with our security and support guidance in SECURITY.md.

For the full text of the Contributor Covenant v2.1, see: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
