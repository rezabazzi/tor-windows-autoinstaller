# Contributing

Thanks for your interest in contributing! A few guidelines to help contributions go smoothly:

- File issues for bugs and feature requests using the provided templates.
- Fork the repository and create a feature branch for your changes.
- Keep changes focused and use clear commit messages.
- Include tests or manual test steps for bug fixes and new features where possible.
- Run `Invoke-ScriptAnalyzer` (PSScriptAnalyzer) on PowerShell files before opening a PR.

When opening a pull request, include a short description of the problem, the solution, and any testing steps.
